# Revit add-ins

- [`OpenBepSync/`](OpenBepSync/): syncs a model's shared parameters with the binding list exported from the BEP Builder, builds the family library, and replaces, merges and renames materials from a checked replace list. Built for Revit 2022; first run in Revit pending. Test files in [`OpenBepSync/test/`](OpenBepSync/test/).

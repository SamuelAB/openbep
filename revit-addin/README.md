# Revit add-ins

- [`OpenBepSync/`](OpenBepSync/): syncs a model's shared parameters with the binding list exported from the BEP Builder, builds the family library, replaces, merges and renames materials from a checked replace list, makes plans for many levels at once named by the OpenBEP view rule, and checks an existing model's names against the rules with a plan of renames to review. Built for Revit 2022; first run in Revit pending. Test files in [`OpenBepSync/test/`](OpenBepSync/test/).

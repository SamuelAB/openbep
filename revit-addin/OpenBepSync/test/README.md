# Test files

A binding list and a shared parameter file exported from the BEP Builder's school renovation example (app v0.37). Use them to try **OpenBEP › Sync parameters** on a copy of a model or on a new project, without exporting your own first.

1. Open a copy of a model, or start a new project from a template.
2. Click **OpenBEP › Sync parameters** and pick `OpenBEP-parameter-bindings-school-example.csv`. The add-in finds the .txt in the same folder.
3. Read the dry run and the report written next to the CSV, then choose **Add and bind the missing parameters**. One Undo reverses it.

To refresh them, export both files again from the Builder (step "Element requirements") with the school example loaded.

Listes de noms

Tous les noms que fixe OpenBEP, au même endroit : les règles que suit chaque nom, les fichiers de maquette, les niveaux et les vues, les paramètres partagés Revit, les matériaux, les motifs et styles de ligne, les types de texte et de cote, et les familles. Utilisez ces noms tels quels, pour qu’une même chose porte le même nom dans chaque maquette et chez chaque firme.

Les noms sont du code : en anglais, sans accents, et commencent par OB_. On les garde tels quels dans une maquette en français; cette page en donne le sens en français. Chaque liste se télécharge en CSV, qui s’ouvre dans Excel.

Garder les listes fermées

  • Les matériaux, motifs de ligne, styles de ligne, types de texte et motifs de remplissage viennent du gabarit seulement. Les familles d’anciens projets ou d’Internet sont nettoyées avant d’être chargées.
  • Une firme peut ajouter jusqu’à cinq styles de texte pour son propre travail (les annotations en rouge, par exemple). Au-delà, on s’entend avec le responsable BIM du donneur d’ouvrage et on les nomme OB_X_, pour qu’ils ressortent à la remise.
  • Pas de texte dans les familles : utilisez une étiquette ou une annotation. Les hachures viennent des matériaux ou des régions remplies, jamais de lignes ni de DAO.

Niveaux

Un seul jeu de niveaux pour tout le projet, qui appartient à la maquette LOCATION; toutes les autres maquettes les copient et les contrôlent sous les mêmes noms. Les étages sont nommés comme on les dit (2ND-FLR), et jamais avec une élévation dans le nom.

Un bâtiment type, en coupe. Les traits pleins sont les étages (Building Story coché, un étage IFC chacun). Les traits pointillés sont les niveaux intermédiaires : le numéro de l’étage du dessous, une décimale, puis des mots, sans étage à eux. Dessiné à l’échelle.

CodeNiveauBuilding Story (étage)
  • Les étages, c’est le numéro ordinal et FLR : 1ST-FLR, 2ND-FLR, 11TH-FLR. Le rez-de-chaussée est 1ST-FLR.
  • Le toit prend le numéro qui suit le dernier étage : 4-ROOF au-dessus d’un 3RD-FLR. Les sous-sols sont BSMNT-1, BSMNT-2.
  • Niveaux intermédiaires : l’étage du dessous, une décimale qui dit à quelle hauteur de l’étage il se trouve (.5 à mi-hauteur, .9 juste sous l’étage suivant), puis des mots qui disent ce que c’est : 1.5-STAIR-LANDING, 1.9-US (dessous du 2e étage), BSMNT-1.5-LANDING. Building Story décoché.
  • Pas de niveau pour un parapet : il est généralement plus simple de donner aux murs du parapet un décalage constant par rapport au niveau du toit.
  • Une mezzanine s’appelle 1.5-MEZZ, avec Building Story coché quand elle compte comme un étage pour le code du bâtiment ou les superficies. Le plan précise lequel des deux.
  • Les mots pour les dessins (Rez-de-chaussée, 2e étage) vont dans le Title on Sheet de chaque plan.

Vues

L’arborescence du projet regroupe les vues sur quatre niveaux : phase, jeu de dessins, type de vue, puis la famille de vue de Revit. Chaque nom de vue reprend la phase, le jeu et le type, puis se termine par le niveau, pour que les noms restent cohérents et qu’une vue copiée n’ait jamais à être renommée.

Filtres de phase

Les noms de Revit lui-même. Deux des sept filtres de Revit sont supprimés parce qu’aucun dessin n’en a besoin, et un est ajouté. Chaque gabarit de vue fixe le filtre, pour que personne n’ait à le choisir à la main. La démolition est un état de l’élément, pas une phase.

Types de vue (OB_ViewType)

Un numéro à trois chiffres en tête classe les dossiers dans un ordre fixe : 3D, site, plans d’étage, plafonds, coupes, élévations, détails. Les numéros libres servent aux types propres à un projet. Le nom de la vue reprend le type sans son numéro.

Comment se lit un nom de vue

Modèle . Une vue sans niveau se termine par ce qui la distingue (N-CON-SECT-STAIR-01); les options de conception se terminent par -OPT1, -OPT2; les vues d’une personne vont dans son propre jeu (N-Z-USER-SAM-PLAN-2ND-FLR). Les vues de dessin n’ont pas de phase, alors DRAFT prend sa place : DRAFT-CON-DET-PARAPET (une proposition). Le paramètre Title on Sheet porte le titre imprimé, pour que les codes n’apparaissent jamais sur les dessins.

    Matériaux

    Nommés OB_<Class>_<Material>_<Detail> : la classe d’abord, pour que tout le bois se retrouve ensemble, puis le matériau, puis ce qui le distingue. N’ajoutez l’usage que s’il change le matériau : un plancher de chêne et des lattes de plafond en chêne sont deux matériaux, le même béton dans les murs et les planchers n’en est qu’un. Jamais la marque ni l’épaisseur. Les noms ci-dessous sont des exemples du modèle de nom, pas une liste fermée.

Naming lists

Every name OpenBEP fixes, in one place: the rules every name follows, model files, levels and views, Revit shared parameters, materials, line patterns and styles, text and dimension types, and families. Use these names as they are, so the same thing has the same name in every model and from every firm.

Names are code: English, no accents, starting with OB_. French users read the French label next to each name. Each list can be downloaded as a CSV that opens in Excel.

Keep the lists closed

  • Materials, line patterns, line styles, text types and fill patterns come from the template only. Families from old projects or the internet are cleaned before loading.
  • A firm may add up to five text styles for its own work (red-marking, for example). Anything more is agreed with the owner's BIM lead and named OB_X_, so it shows at handover.
  • No text inside families: use a tag or an annotation. Hatching comes from materials or filled regions, never from lines or CAD.

Levels

One set of levels for the whole project, owned by the LOCATION model; every other model copy-monitors them under the same names. Short codes that sort the way the building stacks, and never an elevation in the name.

Rules, files, levels and views (.csv)

An example building in section. Solid lines are storeys (Building Story ticked, one IFC storey each). The dashed line is a reference level: it has its storey's code first and no storey of its own. Not to scale.

CodeLevelBuilding StoryNiveau (FR)
  • Two digits after L, so L10 sorts after L09. The ground floor is L01.
  • A mezzanine is L01M when it counts as a storey for the building code or areas; otherwise it is a reference level. The plan says which.
  • The words (Ground floor, Rez-de-chaussée) go in each plan's Title on Sheet, not in the level name.
  • Structure and MEP add only the reference levels they need (L02_TOS, top of steel), with Building Story off.

Views

The project browser groups views in four levels: phase, drawing set, view type, then Revit's own view family. Every view name repeats the phase, set and type, then ends with the level, so names stay consistent and a copied view never needs renaming.

Phases

CodeRevit phasePhase (FR)

One new phase uses N; a phased project numbers them P1, P2.

Drawing sets (OB_ViewSet)

The folder is in full words; the view name carries the short code. Sets starting with Z- sort last, one browser filter hides them all, and they are left out at handover.

Code in the nameFolderHoldsEnsemble (FR)

View types (OB_ViewType)

A three-digit number in front sorts the folders in a fixed order: 3D, site, floor plans, ceilings, sections, elevations, details. The gaps are for a project's own types. The view name carries the type without its number.

TypeViewVue (FR)

How a view name reads

Pattern . A view with no level ends with what tells it apart (N-CON-SECT-STAIR-01); design options end with -OPT1, -OPT2; a person's own views go in their own set (N-Z-USER-SAM-PLAN-L02). Title on Sheet carries the printed title, so the codes never reach the drawings.

    Materials

    Named OB_<Class>_<Material>_<Detail>: class first so all the wood lists together, then the material, then what sets it apart. Add the use only when it changes the material: oak flooring and oak ceiling slats are two materials, the same concrete in walls and floors is one. Never the brand or the thickness. The names below are examples of the pattern, not a closed list.

    Example names

    NameClassCounted in take-offsLabel (FR)
    • OB_<Class>_Generic (OB_Concrete_Generic) when the class is known but not the exact material, at LOD 100 and 200. Counted.
    • OB_Generic_<Kind> (OB_Generic_Plastic) for materials nobody counts: furniture, equipment, appliances and fixtures. The thirty plastics of a loaded toaster become one. Take-offs skip them.
    • Materials brought in by loaded families are renamed to a listed name, inside the families too, after a person approves the old-to-new list.
    • A project's own additions use OB_X_ and are reported at handover.
    • Default, <By Category> or a Revit default name counts as no material from LOD 300 on.

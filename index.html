Vague BIM is useless BIM.

OpenBEP builds a BIM Execution Plan from the uses the owner actually needs: who models what, to what level, by when, and how it is checked.

It is free and open. On this site your work stays in your own browser. For real projects, which hold private information, run your own copy.

Build a BEPStart a blank plan or open one of the two examples (a school and a light rail line). Open a project fileContinue a plan you saved as a project file (.json). Read the LOD specWhat each level of development means for each element type: the geometry and the parameters it must carry.

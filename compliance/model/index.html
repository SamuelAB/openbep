    The model, coloured by compliance

    Use another results file

    The page reads one file in the format openbep-compliance-elements, described in FORMAT.md. The file stays in your browser.

    • Compliance is the required values that are filled, out of the required values. A value is required on an element only where the plan asks for it.
    • Colours: green, every required value on the element is filled. Yellow, at least half. Red, less than half. Grey, nothing is asked of that element by the check you are looking at.
    • Order of the levels: model, workset, category, family, type, element, then each required value on that element. A level with only one group is passed through and shown in the path.
    • OpenBEP writes the plan. It does not check models. The 3D view is VIM's open web viewer (vim-web, MIT licence) and the results come from the file.
